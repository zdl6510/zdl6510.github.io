ShareX：截图、录屏和自动上传工具使用指南

ShareX 是一款开源的 Windows 截图、录屏和自动化上传工具。它适合写教程、记录软件问题、制作操作演示，也适合需要频繁处理图片链接的人。和普通截图工具相比，ShareX 的强项是“截图之后还能继续做很多事”：标注、保存、复制、OCR、上传、生成链接，都可以串成固定流程。

适合什么场景

  • 写博客或教程时，需要快速截步骤图、加箭头、加编号。
  • 遇到软件报错时，需要截图、标注重点并发给别人。
  • 做项目记录时，需要录一段 GIF 或短视频展示操作过程。
  • 需要把图片上传到图床、对象存储或其他托管服务，并自动复制链接。
  • 临时从截图里识别文字，省去手动抄报错信息。

常用功能

  • 区域截图：框选屏幕的一块区域，适合截教程局部。
  • 窗口截图：直接截当前窗口，边界更干净。
  • 滚动截图：用于网页、长列表、文档页面。
  • 屏幕录制：支持视频录制，也能录制 GIF。
  • 图片编辑器：添加箭头、矩形、文字、编号、模糊、马赛克。
  • OCR：识别图片中的文字，适合提取错误日志和提示文本。
  • 截图后动作：自动保存、复制到剪贴板、打开编辑器、上传。
  • 上传后动作：自动复制 URL、复制 Markdown 图片格式等。

基础使用方法

  1. 安装 ShareX 后，先打开“快捷键设置”。
  2. 给“矩形区域截图”“窗口截图”“屏幕录制 GIF”“OCR”设置自己顺手的快捷键。
  3. 打开“截图后的动作”，勾选“保存图片到文件”和“复制图片到剪贴板”。
  4. 如果经常写教程，可以再勾选“打开图片编辑器”，截图后直接进入标注界面。
  5. 需要上传图片时，进入“目标设置”，配置自己的图床、对象存储或平台账号。
  6. 打开“上传后的动作”，选择“复制 URL 到剪贴板”，上传完成后就能直接粘贴链接。

推荐配置

我建议先从三个快捷键开始配置：

  • 区域截图：最常用，适合日常记录。
  • 屏幕录制 GIF：适合展示一个短操作。
  • OCR：适合从报错截图中提取文字。

截图后的动作不要一开始开太多。先使用“保存到文件 + 复制到剪贴板”，确认顺手后，再加“打开编辑器”和“上传图片”。这样更容易定位是哪一步造成干扰。

使用技巧

  • 写教程时，用编号工具标出步骤顺序，比一堆箭头更清楚。
  • 遮挡敏感信息时优先用马赛克或模糊，不要只用半透明色块。
  • 录 GIF 前尽量缩小录制区域，文件体积会小很多。
  • 如果上传失败，先检查目标服务配置，再检查代理、网络和 API 密钥。
  • 只做本地截图也没问题，不配置上传服务照样很好用。
