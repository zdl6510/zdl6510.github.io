上一期我们介绍了基础的 Claude Code安装，这一期开始我们就要开始进行 Claude Code使用技巧的学习，现在我们坐稳扶好准备发车！！！ :rainbow:

[TOC]

1.工作区介绍

经过上期吗，我们安装了 Vsocde的 Claude Code插件，拜托了 CLI方式较为复杂晦涩的操作界面，接下来我们就先来学习一下他的基础功能。

1.1 会话管理

点击这个橙色的按钮，可以增加多个会话，每一个会话都拥有独立上的上下文，也就是我们所说的拥有独立的记忆，就和我们在使用 Chat APP一样的效果，每一个会话之间不会u相互干扰，这样可以让 AI更加专注的解决精细的问题。

比如现在我在一个会话里面告诉 Claude Code我的名字，再通过另一个会话询问 Claude Code。就可以看出他们之间的 记忆隔离

现在通过点击橙色的小按钮或者是 点击 New Session按钮创建一个新的会话，再次询问他我的名字是什么，即可验证~~

可以看出 会话之间不存在记忆互通，但是我的 Claude Code还是通过一些渠道找到了一些信息，所以在AI时代大家要更加注意自己的信息隐私安全！！ :warning:

在新会话按钮的旁边有一个时钟样式的按钮，哪个就是 历史会话管理，点开可以看到之前在该工作区和 Claude Code的对话记录，也就是说 丢失的记忆可以在这里找回来，如果不慎将一个重要的会话关闭了，可以在这里找回。

2. 文件引用与对话流程

在 Claude Code的对话中也是支持我们自己上传的资料作为，Claude Code的思考依据的

同时我们也可以指定特定的文件来作为这一轮对话的参考，比如我的工作区中有两个文件，可以使用 @ + 指定文件名称的方式来对这个文件的信息进行询问或者是直接使用 Claude Code编辑

接下来我们也可以看到，在对话框的下面有一个斜杠的按钮点开之后可以看到非常多的操作。这个其实在 Claude Code CLI也是可以看到的，但是 VScode插件就更加的 平民化一些，可以直接通过搜索和点击按钮的方式，来进行进行交互，常见的操作这里，到了后面会结合具体的操作来展示这里主要的功能，这里我们先按下不表，感兴趣的同学就可以自行搜索一下。

当然这里每一个 AI输出的每一个 次元都是大家的真金白银，在操作是也会难免有手误的时候，当觉得询问的问题不具体或者是询问的方向错误等问题想要终止当前的对话，可以直接点击旁边的按钮终止流程
